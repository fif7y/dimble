# Dimble 0.4.1-beta.10

Tenth beta of 0.4.1, on the beta channel only (Settings › About › "Get beta releases"). One addition, one change and two fixes. If nothing big comes up, this is what goes out in the next stable release.

New:

- Set Menu Bar Layout also takes a file (#169, thanks @rebdeg). A layout you saved from Get Menu Bar Layout goes straight in, with no Get Text step before it. Shortcuts that give it text keep working.

Changed:

- The log says when a Time Machine backup starts and ends, and when one came and went before Dimble checked (#167, thanks @brianaweeks1). It's to find out why the Time Machine icon set to "While backing up" doesn't come out for everyone.

Fixed:

- fn C opens Control Center however long you hold the keys (#179, thanks @mityeah). Dimble opened it as the keys went down and macOS closed it again when you let go, so it flickered or didn't show up. It waits until you let go now. I tested it on macOS 27.3.
- An Always Hidden icon that ended up among your Hidden ones stays hidden with a Live Activity up. Battery showed all through a call on a display that shows every icon, and each time you hovered to show the hidden icons. It can still flash for a second as the Live Activity starts.
