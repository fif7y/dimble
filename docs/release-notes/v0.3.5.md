# Dimble 0.3.5

One fix. If you run a Windows app through Wine (Steam, Crossover, Proton), Dimble could take gigabytes of memory, and your icons wouldn't hide.

Fixed:

- Dimble no longer climbs a folder path forever looking for the app behind a menu bar icon (#133, thanks @ZeLebo). Wine puts a doubled slash in the paths it writes, and the climb up one of those never reached the top. It took a core, grew by gigabytes a minute, and left your icons showing. Nothing else has changed since 0.3.4.
