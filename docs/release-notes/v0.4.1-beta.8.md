# Dimble 0.4.1-beta.8

Eighth beta of 0.4.1, on the beta channel only (Settings › About › "Get beta releases"). Three additions, one change and five fixes. If nothing big comes up, the next release is 0.4.1 for everyone.

New:

- Dimble has Shortcuts actions (#169, thanks @rebdeg). Get Menu Bar Layout gives back your whole layout as text, and Set Menu Bar Layout puts every icon where that text says, in one go. The same text works on another Mac. Others move an icon, add or remove a separator, show or hide the hidden icons, open an icon, turn reveal on hover or on click on and off, and open Search.
- `dimble://` links do the smaller changes without Shortcuts (#169). `dimble://move?icon=Tailscale&to=hidden` moves an icon, and there's `show`, `show-all`, `hide`, `toggle`, `add-separator` and `remove-separator`. Any web page can open a link, so links never read anything back, click an icon, change a setting or set the whole layout.
- `dimble://search?q=Tailscale` opens Search with the text typed in, for Alfred and the like (#146, thanks @ssbodda-powern).

Changed:

- The line between Hidden and Always Hidden is off unless you turn it on (#171, #149, thanks @bortolatto-creator and @openforfuture). It's in Settings › Behavior › Reveal, "Show a line between Hidden and Always Hidden".

Fixed:

- Apply reaches Hidden icons that sit behind macOS's « when Always Hidden is out (#171, thanks @bortolatto-creator). A Hidden icon left of the Always Hidden ones ends up behind the « on a full bar, where Dimble couldn't read its place, so nothing counted it as out of order. After a full reveal it now shows in Apply's count, and Apply opens the « to move it.
- Apply waits until it can read the bar. macOS can stop listing the menu bar's icons for a few seconds, and an Apply in that moment took every icon for gone, dropped the changes and moved nothing. It now waits up to 6 seconds, and keeps the changes if the bar still can't be read.
- With several displays, Dimble could stop responding until you quit it. It asked macOS to watch the menu bar again at almost every reveal, and each time used nearly all the threads an app may have. It now asks once per launch, which makes the hang (seen once in testing) much less likely.
- Live mode steps aside while a full-screen app has the bar. Its cover stayed up as a block at the top of a full-screen video for about 13 seconds.
- Show in Bar from Search brings a Hidden icon out on a display that hides it, while another display is set to always show Hidden. Dimble took the icon for already out.
