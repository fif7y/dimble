# Dimble 0.4.0-beta.3

Third beta of 0.4.0, on the beta channel only (Settings › About › "Get beta releases"). Two fixes, both for things Dimble got wrong on its own, before you touched anything.

Fixed:

- A Focus that was already on before you logged in now shows on the bar (#92, thanks @juanfcocontreras). A Do Not Disturb schedule that started while the Mac was off left the Focus item blank until the Focus next changed. At that moment macOS logs nothing that names the Focus it's already in, so Dimble had nothing to read.
- An icon you can see on the bar no longer turns up in "Didn't fit" (#137, thanks @ycl-2004). With several Spaces on one display, macOS lists a menu bar for each of them, and two of those lists gave one icon two different names at the same spot. Dimble read that as an icon too many, so it waited on a bar that was overflowing and drew the chevron for icons that were never behind it.
